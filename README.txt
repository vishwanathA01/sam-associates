SAM & ASSOCIATES — BEAUTIFUL PHP WEBSITE
=========================================
1. Copy the folder into XAMPP htdocs OR run from the project folder:
   php -S localhost:8000

2. Open:
   http://localhost:8000/
   OR http://localhost/sam_associates_beautiful/

3. If using MySQL, visit /setup.php once.
   Admin: info.sam2026@yahoo.com
   Password: mahesh@1234

The website uses relative/detected asset paths so CSS, JS and images work both
at the web root and inside an XAMPP subfolder. Business-card image is NOT used.
The supplied SAM logo is used in the header/footer and the advisor image appears
in the homepage and About section.
